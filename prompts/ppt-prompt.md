# PPT Style Prompt Guidelines

## Visual Identity

Presentation slides prioritize readability at distance, visual appeal, and clear information hierarchy. Hand-drawn aesthetics make slides feel approachable and engaging.

## Layout Rules

- **Generous spacing**: 50px+ gaps between major elements
- **Relaxed grid**: No strict alignment required, visual balance matters more
- **Center-weighted**: Key content centered, supporting elements around edges
- **Single focus**: Each diagram communicates one main idea

## Color Rules

- Full vibrant palette encouraged:
  - Blue `#1971c2`, Teal `#0c8599`, Orange `#e8590c`
  - Green `#2f9e44`, Purple `#7048e8`, Red `#e03131`
- Use fill+stroke pairs for depth (e.g., `#a5d8ff` fill + `#1971c2` stroke)
- Background: white or very light gray
- Decorative elements (numbered circles, badges, icons) are welcome

## Typography Rules

- Font: any (`fontFamily: 3` default), or Virgil (`fontFamily: 1`) for handwritten feel
- Title: 28pt, subtitle: 16pt, body: 16pt, labels: 13pt
- Use emoji or Unicode symbols for visual markers: ✓ ✗ ↑ ↓ →
- Multi-line labels in boxes are preferred over long single lines

## Shape Rules

- Rounded corners on rectangles (`roundness: type 3`)
- `roughness: 1` (slight hand-drawn feel)
- Borders: 2pt
- Use filled shapes with contrasting stroke for emphasis
- Ellipses for callouts and highlights
- Numbered circles for step indicators

## Arrow Rules

- Arrow width: 2pt
- Curved or straight, whatever looks best
- Color arrows by their semantic role (blue for data, green for success, red for error)
- Add arrow labels freely — text along arrows is encouraged

## Common Patterns

### Flow Diagram with Steps
Numbered circles above each box, descriptive sub-cards below, connecting arrows with labels.

### Concept Map
Central concept in large ellipse, related concepts in surrounding labeled rects, arrows showing relationships with descriptive labels.

### Before/After Comparison
Two columns with header badges showing "Before" and "After", color-coded elements (red → green).

### Timeline
Horizontal line with milestone dots, cards above with descriptions, reference labels below.
